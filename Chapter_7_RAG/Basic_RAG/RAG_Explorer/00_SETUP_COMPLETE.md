## 🚀 Quick 3-Step Start

```bash
# 1️⃣ Setup Backend
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
echo GROQ_API_KEY=your_groq_key > .env
python app.py

# 2️⃣ Setup Frontend (new terminal)
cd frontend
npm install
npm start

# 3️⃣ Use It
Open http://localhost:3000 in browser
```
